# Implementation Guide: `dartfx-workspace-api`

## Architecture
- **FastAPI Entrypoint (`workspace_api/main.py`)**: Configures ASGI lifespan (`init_db()`), `ForwardedPrefixMiddleware` for `X-Forwarded-Prefix` gateway routing, configurable `CORSMiddleware`, `/asyncapi.json`, `/ui` HTML delivery, and `/ui/static` assets.
- **Persistence (`workspace_api/orm.py`, `workspace_api/db.py`)**: SQLAlchemy 2.0 engine configured via `DATABASE_URL` with tables `spaces`, `workspaces`, `api_keys`, and `jobs`. On initial startup, provisions a default `public` Space and `sandbox` ephemeral Workspace via `dartfx.workspace.Space.provision_ephemeral_workspace`.
- **3-Tier Auth (`workspace_api/auth.py`, `workspace_api/dependencies.py`)**: Resolves `X-API-Key`, `Authorization: Bearer`, or `?api_key=` into a `dartfx.workspace.Principal` (`anonymous`, `user`, `admin`) and enforces `dartfx.workspace.AccessPolicy` alongside Space and Workspace storage quotas.
- **Async Job Manager (`workspace_api/jobs.py`, `workspace_api/asyncapi.py`)**: Runs `dartfx.workspace.tasks` in worker threads, persists `JobRecord` updates in the database, fans out `TaskEvent` frames to SSE and WebSocket `asyncio.Queue` subscribers, and dispatches optional HTTP POST webhooks.
- **Canonical Web Client (`workspace_api/static/`)**: Pure HTML/CSS/Vanilla JS SPA computing its API prefix dynamically from `window.location.pathname` so it operates transparently at `/` or behind reverse-proxy subpaths. Includes User and Admin consoles, file explorer with Origin badging (`User` vs `System`), origin filtering, context-sensitive action buttons (`Fairify`, `To CSV`, `Preview`, `Download`, `Delete`) governed by `applicable_actions`, SPARQL/SQL runners, and real-time SSE progress drawers.
- **File Provenance & Command Guardrails**: REST endpoints `/workspaces/{ws_id}/fairify` and `/workspaces/{ws_id}/readstat` validate file eligibility upfront. FAIRification strictly rejects system-generated profiling outputs (such as QSV frequency tables, stats, schemas, or indexes) and requires user-provided CSV or Parquet files. Conversion via ReadStat strictly requires SAS, Stata, or SPSS files (`dta|por|sas7bdat|sav|xpt|zsav`).
- **Cascading Artifact Renames & Cleanup (`routers/files.py`)**: `POST /workspaces/{ws_id}/files/move` cascades dataset renames to all related system-generated FAIRification sidecars on disk and in the Knowledge Base, preserving each artifact's stable UUID and maintaining `up_to_date` status. `DELETE /workspaces/{ws_id}/files` automatically purges related sidecars when a user dataset is deleted (`delete_artifacts=True`), removing them from disk and the Knowledge Base in a single transaction while preserving primary datasets during direct sidecar deletion.
- **Workspace Governance & Settings (`routers/workspaces.py`)**: `GET /workspaces/{ws_id}/settings` and `PATCH /workspaces/{ws_id}/settings` (Admin) manage `dartfx.workspace.policy.WorkspaceSettings`, enforcing `same_format` renames and path-based zone ingestion rules across file uploads and moves (`400 Bad Request` on `PolicyViolationError`).
